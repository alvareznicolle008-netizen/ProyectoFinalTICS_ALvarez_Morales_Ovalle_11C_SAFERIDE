Contexto e Ingeniería de Seguridad 🎡

En atracciones de alta concurrencia como las del IRTRA Petapa, la proximidad inadvertida de usuarios a ejes mecánicos móviles representa la causa principal de emergencias.

SAFE RIDE automatiza la prevención mediante sensores ultrasónicos de alta frecuencia que identifican invasiones perimetrales instantáneamente, cortando riesgos antes de que ocurra una colisión. 🤖✨

✴ Lógica de Control

Zonas de Detección de Proximidad

Monitoreo dinámico continuo mediante lógica de control en C++:

🚨🛑

Zona de Peligro

Invasión crítica a distancia menor o igual a 15 cm.

Respuesta: LED Rojo Encendido + Buzzer Sonoro Continuo.
⚠️🟡

Zona de Precaución

Aproximación en rango intermedio de 16 cm a 50 cm.

Respuesta: LED Amarillo Parpadeante (Advertencia).
🟢✅

Zona Segura

Perímetro despejado a más de 50 cm del peligro.

Respuesta: Sistema en reposo / Operación normal.
🔒 Módulo Complementario

Verificación de Arnés de Seguridad (Sensor LDR)

El sistema valida la colocación física del arnés de protección individual en los asientos del juego mecánico mediante sensores ópticos LDR. El LED verde se enciende para autorizar la marcha del juego solo cuando la hebilla de seguridad está correctamente asegurada. 💡🔒

Código en C++ Nulo-Bloqueo 👨‍💻

Programación en texto estructurado utilizando milisegundos (`millis()`).

// SAFE RIDE - SISTEMA DE SEGURIDAD IRTRA PETAPA
// Catherine, Kimberly y Paula

const int TRIG_PIN = 4;
const int ECHO_PIN = 5;

const int LED_AMARILLO = 2; 
const int LED_VERDE = 3;
const int LED_ROJO = 9;

const int BUZZER_PIN = 10;
const int LDR_PIN = A0;

const int DISTANCIA_PELIGRO_CM = 15;     
const int DISTANCIA_PRECAUCION_CM = 50;   
const int LDR_UMBRAL_ARNES = 500;

unsigned long tiempoAnterior = 0;
const long intervaloParpadeo = 250;       
int estadoLedAmarillo = LOW;

void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);

  pinMode(LED_AMARILLO, OUTPUT);
  pinMode(LED_VERDE, OUTPUT);
  pinMode(LED_ROJO, OUTPUT);

  pinMode(BUZZER_PIN, OUTPUT);

  Serial.begin(9600);
}

long medirDistanciaCM() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);

  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);

  digitalWrite(TRIG_PIN, LOW);

  long duracion = pulseIn(ECHO_PIN, HIGH, 30000);

  if (duracion == 0) return 999;
  return duracion * 0.034 / 2;
}

void loop() {
  int ldrValor = analogRead(LDR_PIN);
  long distancia = medirDistanciaCM();

  unsigned long tiempoActual = millis();

  // 🔴 ALERTA DE PELIGRO CRÍTICO
  if (distancia <= DISTANCIA_PELIGRO_CM) {
    digitalWrite(LED_ROJO, HIGH);
    digitalWrite(LED_AMARILLO, LOW);
    tone(BUZZER_PIN, 1000);
  } 
  // 🟡 ADVERTENCIA PREVENTIVA
  else if (distancia <= DISTANCIA_PRECAUCION_CM) {
    digitalWrite(LED_ROJO, LOW);
    noTone(BUZZER_PIN);
    
    if (tiempoActual - tiempoAnterior >= intervaloParpadeo) {
      tiempoAnterior = tiempoActual;
      estadoLedAmarillo = (estadoLedAmarillo == LOW) ? HIGH : LOW;
      digitalWrite(LED_AMARILLO, estadoLedAmarillo);
    }
  } 
  // 🟢 ZONA DESPEJADA
  else {
    digitalWrite(LED_ROJO, LOW);
    digitalWrite(LED_AMARILLO, LOW);
    noTone(BUZZER_PIN);
  }

  // VALIDACIÓN DE ARNÉS LDR
  if (ldrValor > LDR_UMBRAL_ARNES) {
    digitalWrite(LED_VERDE, HIGH);
  } else {
    digitalWrite(LED_VERDE, LOW);
  }

  delay(100);
}
